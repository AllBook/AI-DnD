# AI-DnD Online

Play AI-DnD with friends in the browser. One person creates a party, everyone
else joins with its four-letter code (or the invite link), and up to six
adventurers fight their way from Thornhaven Village down to the Ancient Crypt.

- **Shared rooms** – live state for every player, reconnect-safe, no accounts.
- **The repo's own rules and content** – the four classes and their abilities
  from `dnd_game.py` (Heavy Strike, Fireball, Backstab, Cheap Shot, Heal), d20
  ability checks, mana, and every item, spell and loot table exported from
  `items.py` / `spells.py`. Monsters are the Goblin, Orc, Skeleton and Bandit
  with their Fury, Rage, Bone Shield and Cheap Shot.
- **AI Dungeon Master** – set `GEMINI_API_KEY` and scenes, victories and
  free-form stunts are narrated by Gemini. Without a key the game uses its
  built-in narration and plays exactly the same.
- **No dependencies** – one Node process, nothing to `npm install`.

## Run it

```bash
cd online
node server.js            # http://localhost:3000
```

With the AI narrator ([get a free key](https://aistudio.google.com/app/apikey)):

```bash
GEMINI_API_KEY=your-key node server.js
```

| Variable | Default | Purpose |
| --- | --- | --- |
| `PORT` | `3000` | Port to listen on |
| `GEMINI_API_KEY` | – | Turns on the AI Dungeon Master |
| `GEMINI_MODEL` | `gemini-2.5-flash` | Model used for narration |

## Put it online

The server needs one long-running Node process (it keeps parties in memory and
holds a Server-Sent Events stream per player), so use a host that runs a
container or a web service rather than serverless functions.

**Render (free tier).** The repository root has a `render.yaml` blueprint.

1. Push this repository (or your fork) to GitHub.
2. Open `https://render.com/deploy?repo=<your repo URL>` and approve the
   blueprint. Paste a Gemini key when asked, or leave it empty.
3. Share the `https://….onrender.com` address with your friends.

Doing it by hand instead: New → Web Service → pick the repo → Root Directory
`online` → Build Command `npm install` → Start Command `node server.js`.

**Anything that runs Docker** (Fly.io, Railway, a VPS):

```bash
cd online
docker build -t ai-dnd-online .
docker run -p 3000:3000 -e GEMINI_API_KEY=your-key ai-dnd-online
```

Free hosts sleep when idle and restart now and then. A restart ends the parties
in progress, because rooms live in memory.

## How a session plays

1. **Lobby** – pick Fighter, Wizard, Rogue or Cleric. Friends can also join
   after the adventure starts.
2. **Camp** – rest (once per camp), search the area (WIS check), buy from the
   quartermaster, or *attempt something*: type anything, pick an ability, and a
   d20 decides while the DM narrates.
3. **Combat** – players act in order, then the enemies. Attack, use a class
   ability, cast a spell, drink a potion, defend, or improvise a stunt. If
   someone disconnects or idles for 45 seconds, anyone can skip their turn.
4. **Six encounters** end with the Rune Warden. Win and you can walk the road
   again with your levels and gear against enemies 35% stronger.

## Files

| File | What it is |
| --- | --- |
| `server.js` | HTTP + SSE server, room codes, optional Gemini narrator |
| `engine.js` | The rules. One JSON room object in, mutated by `act()`; shared by server and browser |
| `data.json` | Items, spells and loot tables, generated by `tools/export_data.py` |
| `public/` | The client (plain HTML, CSS and JS) |
| `test/sim.js` | Bot parties of 1–6 play the whole campaign (`npm test`) |
| `tools/build-artifact.js` | Bundles everything into one page that runs as a Claude artifact |

After changing `items.py` or `spells.py`, refresh the game data from the
repository root:

```bash
python3 online/tools/export_data.py
```
